# drm_1021 — 외부 배포 문서 DRM

CAD 도면 및 문서를 고객사에 전달할 때 **열람 기간**과 **등록된 수신자**를 기준으로 접근을 통제하는 DRM 시스템입니다.

## 핵심 요구사항

| 항목 | 내용 |
|---|---|
| 통제 대상 | 2D CAD(DWG/DXF), 3D CAD(STEP/CATIA/NX/SolidWorks), PDF, Office 문서 |
| 접근 정책 | 등록된 수신자만, 지정된 기간 내에서만 열람. 발신자가 언제든 회수 가능 |
| 사용 범위 | 열람 전용 (편집·저장·인쇄·복사 불가) |
| 열람 환경 | Electron 전용 뷰어(Windows) + 웹 보안 뷰어 |
| 기술 스택 | Node.js / TypeScript, NestJS, Electron, React, PostgreSQL, Redis(BullMQ) |

## 설계 원칙

* **서버 측 정책 강제:** 기간·수신자 검사는 라이선스 서버가 수행하며, 조건 불충족 시 복호화 키를 발급하지 않습니다.
* **중간 포맷 변환 후 암호화:** 원본 CAD는 외부로 전달하지 않고, 2D/문서는 PDF, 3D는 glTF로 변환 후 암호화합니다.
* **클라이언트에 비밀 미보관:** 키는 수명이 짧은 라이선스로만 전달되고 메모리에서만 복호화합니다.
* **추적 가능성:** 수신자별 가시 워터마크와 감사 로그로 유출 경로를 추적합니다.

| 단계 | 범위 |
|---|---|
| 1단계 (MVP) | 컨테이너 포맷, crypto, 라이선스 서버, 발신자 포털, PDF/Office, Electron 뷰어 |
| 2단계 | DWG/DXF 변환, 워터마크 고도화, 회수·감사 대시보드 |
