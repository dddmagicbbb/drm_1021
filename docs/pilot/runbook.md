## 2. 파일럿 환경 구성

```
[파일럿 서버]
  PostgreSQL · Redis · Gotenberg · SMTP(사내 메일 서버)
  apps/server  (TLS 종단 리버스 프록시 뒤, TRUST_PROXY_HOPS=1)
  apps/worker
  apps/portal  (정적 파일, 같은 도메인 /api 프록시)

[수신자 PC]
  DRM 보안 뷰어 설치 파일 (DRM_SERVER_URL=파일럿 서버 주소로 빌드)
```

### 2.1 서버 준비

1. `.env.example`을 바탕으로 파일럿 값 작성. `JWT_SECRET`, `OTP_PEPPER`는 32자 이상 무작위 값을 사용합니다.
2. DB 마이그레이션: `cd packages/db && npx prisma migrate deploy`
3. 서버·워커 빌드 및 기동: `pnpm build` 후 `apps/server`, `apps/worker`에서 `pnpm start`
4. 발신자 계정 생성: `pnpm --filter @drm/server sender:create -- --email <이메일> --name <이름>`
5. 확인: `GET /api/v1/health` → `{"status":"ok","db":"ok"}`

### 2.2 뷰어 설치 파일 준비

1. 서버 서명 공개키 추출: `pnpm --filter @drm/viewer-desktop trusted-keys -- --from-server https://<파일럿 서버>`
2. 서버 주소를 지정해 빌드: `DRM_SERVER_URL=https://<파일럿 서버>` 환경에서 `pnpm --filter @drm/viewer-desktop package` (주소는 빌드 시 고정되며, 설치 패키지는 https 주소만 허용)
3. 코드 서명: `CSC_LINK`, `CSC_KEY_PASSWORD` 설정 후 빌드
4. 산출물 `apps/viewer-desktop/release/DRM 보안 뷰어 Setup <버전>.exe`를 안내 메일의 설치 링크(`VIEWER_DOWNLOAD_URL`) 위치에 게시

## 3. 검증 시나리오

| # | 시나리오 (PRD 4장) | 수행 | 기대 결과 | 결과 |
|---|---|---|---|---|
| 1 | S1 배포 | 발신자가 PDF 1건, DOCX 1건으로 배포 등록 | 두 문서 모두 "배포 완료", 수신자가 안내 메일 수신 | ☐ |
| 2 | S2 열람 | 수신자가 뷰어 설치 → OTP 로그인 → 문서 열람 | 원본과 동일하게 표시, 워터마크에 수신자 이메일·시각 표시 | ☐ |
| 3 | 보호 기능 | 인쇄(Ctrl+P), 복사, 화면 캡처(PrintScreen, 캡처 도구) 시도 | 모두 차단, 캡처 결과에서 뷰어 영역이 검게 나옴 | ☐ |
| 4 | 파일 연결 | 받은 `.drm` 파일 더블클릭 | 뷰어가 열리고 로그인 후 바로 표시 | ☐ |
| 5 | S6 기간 연장 | 발신자가 만료일 연장 | 재배포 없이 계속 열람 가능 | ☐ |
| 6 | S4 회수 | 열람 중 발신자가 수신자 권한 회수 | 최대 10분(라이선스 수명) 안에 뷰어가 문서를 닫고 사유·연락처 표시 | ☐ |
| 7 | S5 만료 | 짧은 기간(예: 1시간) 배포 후 만료 대기 | 만료 후 열람 거부, 안내 문구 표시 | ☐ |
| 8 | 미등록자 | 수신자가 아닌 이메일로 로그인 시도 | 인증 코드 메일 미발송 | ☐ |
| 9 | 기기 제한 | 같은 수신자가 3번째 PC에서 로그인 (기본 2대) | 기기 수 초과 안내 | ☐ |
| 10 | S7 유출 조사 | 감사 로그에서 수신자의 다운로드·열람 이력 조회 (DB 직접 조회, 조회 화면은 2단계) | 시각·IP·기기별 기록 확인 | ☐ |

## 4. 측정 지표 (PRD 8장)

| 지표 | 목표 | 측정 |
|---|---|---|
| 수신자 최초 열람 성공률 | 95% 이상 | `LICENSE_ISSUED` 수신자 수 / 안내 메일 수신자 수 |
| 발신자 배포 소요 시간 | 3분 이내 (변환 제외) | 포털 사용 관찰 |
| 만료·회수 후 열람 성공 | 0건 | 만료·회수 시각 이후의 `LICENSE_ISSUED` 감사 로그 |
| 수신자 문의 | 배포 100건당 5건 이하 | 파일럿 기간 문의 기록 |
